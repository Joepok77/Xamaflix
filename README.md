# Xamaflix

Site de streaming pour voir des films.

## Installation

```bash
# Cloner le projet
git clone https://github.com/Joepok77/Xamaflix.git

# Aller dans le dossier du projet
cd Xamaflix

# Aller dans le dossier react-app
cd react-app

# Installer les dépendances
npm i

# Lancer le projet
npm run dev
```

L'application sera accessible sur `http://localhost:5173`
